# LIMITATIONS — <study name>

**Replication plan (10).** Across dataset samples, readout seeds, and preferably >1 checkpoint /
conversion. Individual component identities need not match if the causal computation does.

**External biological validation (11).** Does the circuit-derived score predict an independent assay /
transcript change better than local motif baselines? Not a biological discovery until it does.

**Explicit failure interpretations (12).** State, in advance, what each negative means: shortcut
reliance vs failure-to-represent vs represents-but-does-not-causally-use vs underpowered readout. A
negative pilot is a result — report it, do not force a circuit trace.
