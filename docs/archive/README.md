# Archive

**[INDEX]** — superseded documents, kept rather than deleted.

**Nothing in this folder may be cited as evidence.** These files record what we believed at the time.
Several contain claims that were later retracted; that is precisely why they are kept — a retraction is
only credible if the thing it retracts is still on the shelf.

Every file below says what replaced it and why. If you find yourself wanting to quote one of these, the
current document listed in the right-hand column is what you actually want.
