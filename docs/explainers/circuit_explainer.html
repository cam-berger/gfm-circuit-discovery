The reading-frame circuit

How we found the machinery, and what it computes — a "find-then-count" mechanism in a 4.8M-parameter genomic transformer.

1 · What it computes

DNA is read three letters at a time. To name the amino acid at any position, the model must know which triplet that position belongs to — the reading frame. It solves this in two moves.

1Find the anchor. Locate the ATG start codon — the one landmark that says where reading begins.

2Count from it. For each position i, compute (i − iATG) mod 3 → the phase (0, 1, or 2).

ATG start (anchor) phase 0 phase 1 phase 2 decoy ATG (ignored)

The 5′ region before the anchor carries no ATG. Every triplet after it inherits its frame from the anchor by counting — that is the whole job.

2 · Where the work happens

Phase is built up across layers, not read off in one step. A linear probe for phase climbs layer by layer — the signature of a computation, not a lookup table.

3 · The proof it counts (try it)

If it truly counts from the anchor, inserting one extra letter should shift the entire downstream frame by exactly one — and the model should follow the anchor, not the local letters. It does, even 250 letters away.

4 · The twist: a perfect-looking head that does nothing

5 · How we found it — the order that mattered

1Built ground truth first. Two toy transformers hand-wired with known internals — one that genuinely counts, one that fakes it — to measure the tracer's error rate and catch its blind spots before trusting it on a real model.

2Made the circuit necessary. On a task where finding the frame is the only solution, the model sat at the guessing floor for ~2,750 steps, then groked — jumping to >0.99 in ~500 steps. No halfway: you can't half-know where triplets begin.

3Traced three independent signatures. Phase built across layers (§2); the start codon causally load-bearing while an identical codon elsewhere is inert; frameshifts propagated exactly like biology (§3).

4Let intervention, not attention, decide (§4) — which is how the inert look-alike head was caught.
