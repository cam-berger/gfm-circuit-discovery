01 · The mechanism, as currently supported

A structured causal core inside a distributed computation

The donor-graph arc A0→A12 dissected the coupling end to end. The named circuit is necessary and sufficient-when-injected, but it is not a sparse generator — which is itself the headline finding.

“A structured, top-ranked causal core binds a predominantly relative positional address to an acceptor-local payload, then delivers the resulting information to the donor readout within an irreducibly distributed computation.”
Address

Where to look

Position-embedding geometry — predominantly relative offset, modest absolute — routed through L2H15 / MLP2; L3H1's attention selects the acceptor.

posn geometry → L2H15 → L3H1 attn
C20 · C22 · C25 · C32
Payload

What is carried

An acceptor-local state built by a serial MLP backbone. Not bulk composition — but its semantic identity is unresolved (“splice-strength” withdrawn, R22).

L0H7/H12/H10 → MLP0 → MLP1 → MLP2
C28 · C29 · C30 · C31
Bind

Address × payload

At L3H1 the positional address and the acceptor value payload are required jointly — a bind-and-convert, not a lookup — into a low-rank donor-side direction U_info.

L3H1 : addr × payload → U_info
C16 · C17 · C23 · C24
Deliver

To the donor readout

Selective transporter heads carry the donor-side information to the masked-donor readout; U_info replicates across disjoint genes.

L5H11 · L4H2 · L4H0 → donor ±5
C18 · C26
Faithfulness

No sparse knee

90% of the effect needs ~72 of 103 nodes; scrubbed faithfulness F=0.005. The core is real and top-ranked, embedded in a distributed remainder.

structured core ⊂ distributed compute

07 · What's next

One experiment gates the paper

Next scientific gate · prereg drafted, not frozen, not run

G1 — cross-example transduction

Almost all donor-graph evidence is intra-example patching on short introns, so it speaks only to that prompt distribution. A reviewer will ask whether the circuit generalizes. G1 answers it.

  • Derive U_info on discovery genes only
  • Inject into gene-disjoint matched targets
  • Require dose-ordered margin movement above matched-random & within-example controls
  • Multi-draw stability + dyadic inference (R22 discipline)

Track 2 — payload semantics & steering

open

What acceptor-local latent is carried, and can it steer which site a donor favours? Semantic identity is the key open problem (C30 / R22).
