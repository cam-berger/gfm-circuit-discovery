# `figures/dnabert_promoter/` — frozen DNABERT-2 promoter figures

Built by `scripts/dnabert_promoter/plot_frozen_figures.py`. Each figure has a `.CAPTION.md` beside it
carrying the narrative and the controlling artifact, per the repository figure convention — the artwork
itself states no claim.

A caption states which artifact controls the figure and what the figure may be quoted for. It supports a
claim; it is not the claim. (The document tier system these captions used to carry was retired on
2026-08-14; see R47.)

**Every figure here now depicts the canonical Layer-2 assay.** That was not true until 2026-08-23:
figures 4–8 were built from the superseded encoder-Layer-3 replicate
(`results/dnabert_promoter/causal/layer3_*`) and did not show the numbers in
[`CLAIMS.md`](../../studies/dnabert_promoter/CLAIMS.md).

## The gap at 4–8

Those numbers are absent by design. The seven Layer-3 figure stems that held them — figures 4, 5, 6, 7
and 8, where 5 and 6 each also had a `_fractions` panel — were retired on 2026-08-23, along with the code
that generated them. Twenty-one files: seven stems, each a `.png`, a `.pdf` and a `.CAPTION.md`.

They had carried `**Status: superseded. Controls no claim. Do not quote.**` in their captions since
2026-08-11, which was judged sufficient at the time. It was not. `figure8_test_donor_matrix` plots a
`PRIMARY_SIX_HEADS` recovery fraction of `0.258` at Layer 3; the confirmed Layer-2 donor matrix behind
`DBP8` reports `0.879` for `L0 MLP + L0H8`. Different experiment, different endpoint, similar name — and
the workshop manuscript's transfer figure was built by someone reading across that gap. A warning label
does not stop a figure from being picked up; removing the figure does.

The Layer-3 **result artifacts** are untouched under `results/dnabert_promoter/causal/layer3_*` and remain
indexed as `DBPR7`. Immutability protects measurements, not artwork. The figures themselves stay in Git
history; recover them by restoring from the parent of the commit that removed them:

```bash
git log --all --full-history --diff-filter=D -- 'figures/dnabert_promoter/figure8_test_donor_matrix.png'
git checkout <that-commit>^ -- figures/dnabert_promoter/
```

The numbering is deliberately not compacted: renumbering would break every existing reference to figures
9–12 to save nothing.

## Regenerating

```bash
uv run --extra dnabert python scripts/dnabert_promoter/plot_frozen_figures.py   # figures 1-3, 9-12
uv run --extra dnabert python scripts/dnabert_promoter/make_paper_figure_transfer.py
```

The manuscript figure has its own script because it re-checks every plotted value against its source
artifact before drawing and writes a `.provenance.json` sidecar; the batch script does neither.

Matplotlib stamps a creation date into PDF metadata, so a rerun produces a non-empty diff for
byte-identical plots; commit only the figures whose underlying artifact actually changed.
