# Figure 2 — Structured donor–acceptor core and its faithfulness boundary

**A.** An acceptor-local value payload is built through L0H7/H12/H10 and the
MLP0→MLP1 backbone. A learned period-3 coordinate contributes to a predominantly
positional address through L2H15. Both streams converge through MLP2 at L3H1, which
writes the rank-8 donor-side readout state \(U_{\mathrm{info}}\). L4H0, L4H2, and
L5H11 transport that state toward the masked-donor MLM margin.

**B.** Held-out complement faithfulness rises gradually with retained head/MLP nodes.
The preregistered interpolation reaches 90% at 64.2 of 103 nodes; the first sampled
set above 90% contains 72 nodes. The named mechanism is therefore a structured
top-ranked core inside a broad interaction-dependent computation, not a complete
sparse generator or a proven minimal set.
