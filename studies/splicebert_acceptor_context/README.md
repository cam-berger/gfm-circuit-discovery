# SpliceBERT acceptor context — prospective branchpoint and pyrimidine-context study

> **Tier: T2 — development.** No live claim or registered model result exists.

This directory preserves the prospective protocol cited by the NeurIPS manuscript's bounded-extension
section and claim-to-artifact map. It asks whether the frozen model's single-`G` acceptor-reconstruction
margin is causally sensitive to a sourced branchpoint window and a deterministically defined
`opPPT80_v1` pyrimidine-rich sequence interval, relative to transition-matched controls.

The purpose is to turn the paper's unresolved acceptor-local content question into a controlled model
experiment. Even a successful target would establish only sensitivity of a frozen MLM endpoint under the
specified interventions. It would not establish a curated polypyrimidine-tract annotation, spliceosome
chemistry, cellular splice usage, or mediation by the donor-side circuit.
