# SpliceBERT acceptor context (design only)

This prospective study would ask whether the frozen model's single-`G` acceptor-reconstruction margin is
causally sensitive to a sourced branchpoint window and to a deterministically defined `opPPT80_v1`
pyrimidine-rich sequence interval, relative to transition-matched controls. It turns the paper's
unresolved acceptor-local content question into a controlled model experiment. The NeurIPS manuscript
cites the protocol in its bounded-extension section and claim-to-artifact map.

Even a successful target would establish only sensitivity of a frozen MLM endpoint under the specified
interventions. It would not establish a curated polypyrimidine-tract annotation, spliceosome chemistry,
cellular splice usage, or mediation by the donor-side circuit.
