# SpliceBERT positional-proxy modifiability

This study is closed at a model-free construction result. Its only live claim is **PPM1**: under the
audited real-module design, the single-checkpoint `Psi` assay needs 718 blocks, but only 544 remain
usable at the required assignment margin. No cohort was selected and no model was loaded.

Start with [`CLAIMS.md`](CLAIMS.md). The controlling artifacts are
`results/splicebert_positional_clock/real_panel_capacity_v1.json` and its independent audit. The
provisional `positional_clock` path is retained because those immutable artifacts record it.

The frozen [`PREREGISTRATION.md`](PREREGISTRATION.md) was never executed. Exploratory behavioral and
continued-pretraining runs were outside that protocol, lacked enough training-seed replication and an
independent audit, and backed no claim. They were removed from the active tree during the evidence
cleanup and remain recoverable at Git tag
`archive/unsupported-exploratory-2026-08-22`.

PPM1 is a capacity result, not evidence about SpliceBERT behavior or splicing biology. It does not
resolve the paired `Delta Psi` design, which still requires a separately powered, preregistered study.
