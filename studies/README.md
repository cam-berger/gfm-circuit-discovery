# Research studies

SpliceBERT donor–acceptor coupling is the main worked example; the other studies test transfer, context
dependence, or the limits of proposed assays. Start with the [project story](../docs/README.md) and the
[evidence audit](../docs/RESULTS.md). In each study, `CLAIMS.md` records what is claimed and its limits.

A construction result is a model-free finding about the assay itself and supplies no model endpoint.
Retained protocols and runners do not authorize reopening a closed execution path.

| Study | Kind | Summary |
|---|---|---|
| [SpliceBERT partner selection](splicebert_partner_selection/README.md) | Model evidence | Masked-donor mechanism and positional carriers: a structured causal core within distributed computation; the payload's biological meaning remains unresolved. |
| [SpliceBERT acceptor coupling](splicebert_acceptor_coupling/README.md) | Model evidence | Reciprocal masked-acceptor behavior and bounded component evidence; the mechanism handoff stopped before target science. |
| [DNABERT-2 promoter](dnabert_promoter/README.md) | Model evidence | Single-seed test of whether the intervention workflow transfers to another model, task, and tokenizer; not a replication of the SpliceBERT mechanism; no frozen preregistration. |
| [SpliceBERT Head–Context Atlas](splicebert_head_context_atlas/README.md) | Model evidence | Component reuse across sequence contexts; does not establish donor-mechanism transfer across contexts. |
| [SpliceBERT GTEx fine-tuning shift](splicebert_gtex_finetune_shift/README.md) | Model evidence | Original-MLM versus native-classifier readouts across published fine-tuning seeds. |
| [SpliceBERT CC/max crossed-register verification](splicebert_register_operator_replication/README.md) | Model evidence | Ψ=+0.430, but frozen resolution failed; no confirmed preference claim. |
| [SpliceBERT acceptor context](splicebert_acceptor_context/README.md) | Prospective design | Draft protocol; no registered model result or live claim. |
| [SpliceBERT positional boundary coherence](splicebert_positional_boundary_coherence/README.md) | Construction result | Capacity failure; no complete cohort or model outcome. |
| [SpliceBERT positional-proxy modifiability](splicebert_positional_proxy_modifiability/README.md) | Construction result | Capacity result; the frozen model protocol was never executed. |
| [Exon-edge compatibility archive](splicebert_exon_edge_compatibility/README.md) | Archive record | Protocols and pointer for donor-ledger C43/C44; no executable study. |

Sibling-checkpoint and cross-model carrier comparisons belong to the donor ledger, with artifacts under
[origin-siblings](../results/origin-siblings/RESULTS_INDEX.md) and
[origin-crossmodel](../results/origin-crossmodel/README.md).

the [transfer guide](../docs/TRANSFER_GUIDE.md). The [script index](../scripts/README.md) and [result
index](../results/RESULTS_INDEX.md) locate code and artifacts.
