# Codon phase-lattice protocol — historical exploratory record

**Status: superseded as an active study; retained for provenance.**

This directory contains the v3 phase-shift preregistration created after the original “42-head codon
phase lattice” was retracted (R14). The earlier purity metric rewarded single-offset copying rather than
repeated stride-3 comb structure, and broad ablation destroyed the measured behavior.

The surviving lesson was incorporated into the active period-3 program under
[`../splicebert_partner_selection/`](../splicebert_partner_selection/README.md): require genuine repeated
comb teeth, protected health controls, carrier deletion, matched restoration, and behavior-level
intervention. Current period-3 claims are C8/C9/C34/C35 in
[`../splicebert_partner_selection/CLAIMS.md`](../splicebert_partner_selection/CLAIMS.md).

[`PREREGISTRATION_PHASE_SHIFT.md`](PREREGISTRATION_PHASE_SHIFT.md) is not an active runner contract and
must not be read as a separate live result family.
